- To develop the InKCre/core-py, following resources are required for you to test and debug so as to verify your changes:
  - PostgreSQL database
    - A Github Action is configured to checkout a database branch (NeonDB) for each PR with database branch name `<branch-name>`. The checked out branch's parent branch is `<pr-target-branch-name>` and schema only (use `develop` as fallback) (the parent branch cannot has legacy web acesss roles)
    - And the schema diff will be commented to the PR (compare to the PR target branch)
    - `copilot-setup-steps` also checked out a database branch for Github Copilot Agent and configure the DATABASE_URL in `.env`.
