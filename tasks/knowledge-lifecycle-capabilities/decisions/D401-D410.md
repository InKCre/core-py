# Decisions D-401–D-410

> [Decision register index](index.md)

### D-401 — Independent JSON batches return ordered correlated atoms with errors only on failed atoms

- **Shape**: every admitted input retains one ordered result atom and its natural correlation key。A successful payload
  proves success；there is no redundant `status: found`。A failed atom contains `error` with a shallow actionable code and
  observable message。
- **Isolation**: one target/call failure does not abort sibling atoms。A normally completed batch with partial failures is not
  an MCP-level error；whole-operation error is reserved for a shared failure that prevented formation of the admitted batch。
- **Validation**: framework/Pydantic still owns top-level Tool input validation。Resolver method arguments are independently
  validated after batch admission so one invalid call can return `invalid_arguments` without cancelling siblings。
- **MCP codes**: the initial public set is `not_found`，`invalid_arguments`，`unavailable` and `failed`。Natural domain
  outcomes such as “no graph path” are not reclassified as execution failures。
- **Task-wide pattern**: promote the shape into experimental API/JSON design taste for independently executable batches；it
  does not apply to semantically atomic or order-dependent commands。
- **Confidence**: explicitly accepted and promoted by Sir。

### D-402 — MCP Sink Acceptance is six real journeys with separate deterministic and probabilistic evidence

- **Accepted artifact**: [`../units/mcp-sink/acceptance.md`](../units/mcp-sink/acceptance.md) owns the exact task-state
  acceptance realization。
- **Deterministic journeys**: Sink protocol lifecycle，composable retrieval，content/Resource delivery，dynamic Resolver
  methods and monotonic Extension publication run through real behavior boundaries and static repository gates。
- **Product journey**: ChatGPT Developer Mode + Secure MCP Tunnel + `use-inkcre` remains manually observed rather than an
  automated model-behavior assertion。
- **Anti-overfit**: acceptance does not add test-only Resolver methods or fake retrieval rows，fix one arbitrary equal shortest
  path，or assert private running maps、SDK internals or `sys.modules` details。
- **Confidence**: Sir reviewed and accepted the exact draft as the implementation gate。
